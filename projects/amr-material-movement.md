# Factory Logistics Automation Project (FLAP)

**Focus:** Smart manufacturing · Autonomous material movement · System integration  
**Environment:** Garment manufacturing  
**Systems and tools:** Hikrobot AGV, RCS, MES, WMS/iWMS, WCS, CTU, PLC, PostgreSQL, REST API

## Overview
FLAP is a factory-logistics automation initiative intended to digitalize material movement and improve the connection between manufacturing operations and logistics systems.

## Work covered
- AGV deployment and operations support in cutting and VAP workflows.
- Configuration and operational management for 37 AGVs, including route planning, task allocation, traffic management, and troubleshooting.
- Implementation activities for four CTUs in the finishing section, including WMS/RCS integration.
- Technical requirements, commissioning, testing, infrastructure planning, technical specifications, BOQs, and budget inputs.
- Coordination with internal engineering, IT, production, maintenance, procurement, finance, R&D, and supplier teams.

## Engineering considerations
Reliable material movement depends on more than the robot itself. Route design, workstation readiness, fleet task logic, network connectivity, integration with factory systems, and a clear operational support process all matter.
