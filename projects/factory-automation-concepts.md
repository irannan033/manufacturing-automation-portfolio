# Factory Automation and Embedded Systems Projects

This page groups selected practical engineering projects and prototypes.

## Pick-and-Light Solution
Integrated an AGV-synchronized material-picking workflow. When an AGV arrives at the material hub, the relevant rack-compartment LED indicators guide the operator to the required material location.

**Focus:** Operator guidance, material picking, AGV coordination.

## Industrial Robotic Arm
Programmed, modified, and set up a six-axis robotic arm for garment-part handling and pick-and-place tasks, with attention to repeatability, cycle time, and safe operation.

**Focus:** Industrial robotics, pick-and-place, work-cell integration.

## IoT-Based Early Flood Detection
Prototyped an ESP32-based flood-monitoring system using distance/water-level sensing and GSM/Wi-Fi notification concepts, with cloud monitoring.

**Tools:** ESP32, HC-SR04, SIM800L, VL53L0X.
