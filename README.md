# Itmam Rubayet Annan — Engineering Portfolio

A responsive personal portfolio for robotics, industrial automation, smart manufacturing, factory logistics, industrial data integration, and power-system modeling.

## Run locally
Open `index.html` in a browser. No build tools or package installation are required. The page uses plain HTML, CSS, and JavaScript.

## Publish with GitHub Pages
1. Upload the repository contents to your GitHub repository.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select branch `main` and folder `/(root)`, then save.
5. After the deployment completes, open the Pages URL shown in Settings → Pages.

## Edit the portfolio
- `index.html`: all visible text, project descriptions, contact links, experience and education.
- `assets/css/style.css`: colors, spacing, layout, typography and responsive behavior.
- `assets/js/main.js`: mobile navigation and footer year.
- `projects/`: longer public-facing project briefs.

Edit through GitHub by opening a file and selecting the pencil icon, or clone the repository and edit with VS Code.

- The CV lists 37 AGVs managed and four finishing-section CTUs implemented; those figures are used in the highlights.
- Review every achievement and project description before external publication. Do not publish confidential factory information, customer data, internal screenshots, IP addresses, credentials, or proprietary operational details.
- Verify that the LinkedIn profile link in `index.html` opens your intended public profile before sharing.
- Add only screenshots, photos, or code that you have permission to publish.
